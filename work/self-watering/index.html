//Self-Watering System

/ Hardware/ Electronics

Automated watering system for indoor plants.

Status
Complete
Board
Arduino Uno
Sensing
Two capacitive moisture sensors, averaged
Output
One relay-controlled low-voltage pump
Logic
Water above 600, 10 s run, 2-day lockout
Ran
3 months
Code
github.com/Tibbboh/Self_Watering

An Arduino Uno averages two capacitive moisture sensors across the soil body. I first tested the sensors in dry and wet conditions to establish a baseline. When conditions require watering, it runs a relay-controlled pump for 10 seconds, then locks out for two days so the water can soak in. It ran for three months with only the tank being refilled. Plant health metrics were not recorded, but the plant remained healthy during the test.

if (averageMoisture > threshold) {   // 600: dry
  if (!pumpActive) {
    digitalWrite(relayPin, LOW);       // pump on
    delay(motorRunDuration);           // 10 seconds
    digitalWrite(relayPin, HIGH);      // pump off
    lastPumpTime = millis();
    pumpActive = true;                 // lockout on
  }
}
if (pumpActive && millis() - lastPumpTime >= twoDays) {
  pumpActive = false;                  // after 2 days
}
